# EcoChange Helper

WTC verification code   WTC-DYLKTNNV


**Exposing the invisible inequality in the air we breathe.**

South Africa has over 200 reference-grade air quality monitors. Yet the public can't easily see what they're measuring. The monitors that exist sit in government networks with delayed publishing, while the low-cost networks that publish live data cover a fraction of the country. This project asks a simple question: **who is actually being measured?**

---

## 🚩 The Problem: Not a monitoring gap — a monitoring *maintenance* gap

Most conversations about air quality assume the problem is "we need more monitors." South Africa doesn't have that problem. It has **221 reference-grade monitors**, according to OpenAQ. That's enough to measure every major city.

The problem is what happens *after* the monitors are built:

- **Of 221 reference-grade monitors, only 131 report PM2.5 data and are active.** Nearly half are offline, stale, or measuring something other than the pollutant that matters most for health.
- **George, a city of ~200,000 people, has five reference-grade monitors.** All five stopped reporting between 2023 and 2024. The nearest *working* monitor is now 110 km away.
- **The AirQo network** (low-cost, real-time, publicly accessible) has just **21 monitors across South Africa** — 18 of them in Gauteng province. Four provinces have none.
- **WAQI** — the most widely-used public air quality aggregator — has no ground monitor within 15 km of Soweto or Sandton, Johannesburg's two most contrasting suburbs.

**This is not "nobody is measuring."** This is "we built the monitors, and then stopped paying attention." That's a harder problem, and a more honest one to name.

## 💡 The Solution

EcoChange Helper is a diagnostic tool that turns raw environmental telemetry into a **human reality check**. Enter a city and a few daily habits, and the app tells you:

- **Today's air quality** at that location, with an honest label for where the number came from (ground sensor, model estimate, or reference monitor 30 km away)
- **Whether the air is being measured at all** — by the networks this app checks
- **What the nearest ground monitor actually is** — its name, its distance, and whether it's currently reporting
- **A carbon footprint estimate** based on your transport, diet, and home energy
- **AI-generated health context and future scenarios** for 2030–2100, clearly labelled as interpretation, not measurement

Every number carries a source label. If the app doesn't know something, it says so.

## ⚙️ How It Works

1. **Data retrieval**
   - **Open-Meteo geocoding + air quality API** — city coordinates and CAMS atmospheric model PM2.5/ozone estimates
   - **AirQo API** — hyperlocal low-cost monitor readings across African cities
   - **WAQI** (World Air Quality Index Project) — nearest-station lookup by coordinates
   - **OpenAQ** — South African reference-grade government monitors, with activity status per monitor

2. **Personal calculation**
   A Flask backend computes a daily CO₂-equivalent score from transport, diet, and home energy.

3. **AI narrative engine**
   Google Gemini interprets the raw readings and generates a short health context, a 2030 forecast, and two future scenarios — all clearly labelled as interpretation, not measurement.

4. **Honest labelling layer**
   Every reading is tagged with source type: `model`, `measured`, or `unavailable`. The template suppresses misleading readings (e.g., a ground monitor 30 km away is shown as *reference only*, not as the area's value).

## 🛠️ Tech Stack

- **Language:** Python 3.12
- **Framework:** Flask
- **AI:** Google Gemini API
- **APIs:** Open-Meteo, AirQo, WAQI, OpenAQ
- **Storage:** SQLite (rolling `readings.db`) + daily CSV snapshots (`data/snapshots/`)

## 🏃 Setup

```bash
git clone https://github.com/Mpilozama/EcoChange-Helper.git
cd EcoChange-Helper
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file in the project root:

```
GOOGLE_API_KEY=your_gemini_key
WAQI_TOKEN=your_waqi_token
AIRQO_TOKEN=your_airqo_token
OPENAQ_API_KEY=your_openaq_key
GEMINI_MODEL=gemini-2.5-flash
```

Initialise the data:

```bash
python -m pipeline.sync_airqo_sites       # downloads AirQo site list
python -m pipeline.sync_openaq_sites      # downloads OpenAQ SA site list
python -m pipeline.coverage_report        # generates data/za_coverage.json
python -m pipeline.ingest                 # runs one ingestion pass
```

Run the app:

```bash
python app.py
```

Open `http://localhost:5000`.

## 🔍 What This Project Does *Not* Claim

Intellectual honesty matters more than a compelling story. This project is careful to distinguish between:

- **"Uncovered by the networks we check"** vs. **"nobody is measuring."** Government networks, private networks, and academic monitoring exist outside the four APIs used here.
- **Model estimates** vs. **ground measurements.** PM2.5 from Open-Meteo is a CAMS atmospheric model at 11–45 km resolution. It cannot resolve neighbourhood-level variation. When a ground monitor exists nearby, its value is shown separately and labelled.
- **Active monitors** vs. **installed monitors.** A reference-grade monitor that stopped reporting in 2023 protects nobody today. The coverage report filters by 30-day activity.
- **AI-generated narrative** vs. **scientific forecast.** The health context and 2030 scenarios are written by Gemini from the raw data. They're evocative, not predictive.

Every claim in this README is reproducible by running the code in this repo.

## 🚧 Limitations and Future Work

- **The map rendering issue on `/coverage`** is known and under investigation (Leaflet container height / OSM tile blocking).
- **Geo-blocking**: OpenStreetMap tiles are blocked in some environments. A fallback tile provider (Carto, MapTiler) is planned.
- **Historical charts**: daily CSV snapshots are being collected but not yet charted. A `/history` page with per-monitor time-series is the next planned feature.
- **More countries**: the coverage report currently covers 15 South African cities. Extending it to Kenya, Uganda, Nigeria (where AirQo has significant coverage) is straightforward.
- **Additional networks**: SAAQIS (South Africa's own reference network) isn't directly queried — its monitors appear via OpenAQ aggregation. A direct SAAQIS integration would be more accurate.
